The basics

Q01
What is the difference between WHERE and HAVING?
Answer
WHERE filters rows before they are grouped. HAVING filters groups after aggregation. That ordering is why you cannot put an aggregate in WHERE — at the point WHERE runs, the groups do not exist yet.

Say the execution order out loud and the answer becomes obvious: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY.
-- wrong: COUNT(*) does not exist yet at WHERE
SELECT department FROM employees
WHERE COUNT(*) > 45 GROUP BY department;

-- right
SELECT department, COUNT(*) AS n
FROM employees GROUP BY department
HAVING COUNT(*) > 45;
Q02
What is the order SQL actually executes a query in?
Answer
Not the order you write it. FROM → JOIN → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT.

Two consequences that get asked as follow-ups: a column alias created in SELECT cannot be used in WHERE (SELECT has not run yet) but can be used in ORDER BY (which runs after). And WHERE cannot see an aggregate.
Q03
DELETE, TRUNCATE and DROP — what is the difference?
Answer
DELETE removes rows, can take a WHERE, is logged row by row, and can be rolled back. TRUNCATE removes every row, takes no WHERE, is much faster because it deallocates pages rather than logging rows, and resets identity counters. DROP removes the table itself — structure, indexes, constraints, the lot.

DELETE and TRUNCATE are DML/DDL respectively; the practical answer an interviewer wants is DELETE is selective and reversible, TRUNCATE empties, DROP destroys.
Q04
What is the difference between CHAR and VARCHAR?
Answer
CHAR is fixed length and pads with spaces; VARCHAR stores only what you put in, plus a length byte or two. Use CHAR when the value genuinely is always the same width — a country code, a Y/N flag — and VARCHAR for anything else. The trap in practice is that trailing spaces in CHAR break equality comparisons people expect to work.
Q05
What does DISTINCT do, and what is the cost?
Answer
Removes duplicate rows from the result. Two things to say beyond the definition: it applies to the whole row of selected columns, not just the first one; and it has to sort or hash the result to find duplicates, so on a large table it is not free. If you are reaching for DISTINCT to fix duplicates, often the real problem is a join that is fanning out rows.

Joins

Q06
Explain the different types of join.
Answer
INNER — only rows that match on both sides.
LEFT — every row from the left table, plus matches; NULLs where there is none.
RIGHT — the mirror image.
FULL OUTER — everything from both, NULLs on whichever side is missing.
CROSS — every row against every row, so 100 × 50 gives 5,000. Almost always accidental.
SELF — a table joined to itself, which is how you handle a manager_id pointing at employee_id.
SELECT e.name, d.department
FROM employees e
LEFT JOIN departments d ON e.dept_id = d.dept_id;
Q07
How do you find rows that exist in one table but not the other?
Answer
A LEFT JOIN with an IS NULL check on the right-hand side — the anti-join. This is a very common live-coding ask.

Say why it works: the LEFT JOIN keeps every left row, and the only rows where the right-hand columns are NULL are the ones that found no match.
SELECT e.*
FROM employees e
LEFT JOIN departments d ON e.dept_id = d.dept_id
WHERE d.dept_id IS NULL;
Q08
Your join returned more rows than the left table had. Why?
Answer
Because the join key is not unique on the right-hand side. One left row matched several right rows, so it was duplicated — the classic fan-out.

The diagnosis: count rows before and after, then check the key with SELECT key, COUNT(*) FROM t GROUP BY key HAVING COUNT(*) > 1. This is the single most useful join debugging answer a fresher can give.
Q09
What is the difference between UNION and UNION ALL?
Answer
UNION stacks two result sets and removes duplicates. UNION ALL stacks them and keeps everything.

UNION ALL is faster because it does not have to deduplicate. Both require the same number of columns with compatible types. If you know the two sets cannot overlap, UNION ALL is the right choice and saying so shows judgement.
Q10
What is the difference between a JOIN and a UNION?
Answer
A JOIN adds columns — it widens the result by matching rows side by side. A UNION adds rows — it stacks two result sets with the same shape on top of each other. Same rows or same columns is the question to ask yourself.

Aggregation and grouping

Q11
What is the difference between COUNT(*), COUNT(column) and COUNT(DISTINCT column)?
Answer
COUNT(*) counts rows, including rows that are entirely NULL in the column you care about.
COUNT(column) counts non-NULL values in that column.
COUNT(DISTINCT column) counts distinct non-NULL values.

The gap between the first two is your missing data count, and that is usually the point of the question.
SELECT COUNT(*)            AS rows,
       COUNT(salary)       AS have_salary,
       COUNT(*) - COUNT(salary) AS missing
FROM employees;
Q12
How do aggregate functions treat NULL?
Answer
They skip it. AVG, SUM, MIN, MAX and COUNT(column) all ignore NULLs rather than treating them as zero. So AVG over a column with two blanks divides by the non-null count, not the row count.

That is usually correct, but it is silent — if you want blanks treated as zero you have to say so with COALESCE.
Q13
Find the second highest salary.
Answer
Three ways, and knowing more than one is the point.

The window-function version is the one to lead with because it generalises to Nth and handles ties explicitly.
-- 1. window function (best answer)
SELECT DISTINCT salary FROM (
  SELECT salary, DENSE_RANK() OVER (ORDER BY salary DESC) AS rnk
  FROM employees
) t WHERE rnk = 2;

-- 2. subquery
SELECT MAX(salary) FROM employees
WHERE salary < (SELECT MAX(salary) FROM employees);

-- 3. LIMIT / OFFSET
SELECT DISTINCT salary FROM employees
ORDER BY salary DESC LIMIT 1 OFFSET 1;
Q14
Find duplicate rows in a table.
Answer
GROUP BY the columns that should be unique and keep the groups with more than one row. If you need the rows themselves rather than the keys, join back or use a window function.
-- the duplicate keys
SELECT emp_id, COUNT(*) AS n
FROM employees GROUP BY emp_id HAVING COUNT(*) > 1;

-- the duplicate ROWS, keeping the first of each
SELECT * FROM (
  SELECT *, ROW_NUMBER() OVER (PARTITION BY emp_id ORDER BY emp_id) AS rn
  FROM employees
) t WHERE rn > 1;
Q15
Show each department's headcount and average salary, highest average first.
Answer
A straight GROUP BY. Worth mentioning that ROUND makes the output readable and that the alias can be used in ORDER BY but not in WHERE.
SELECT department,
       COUNT(*)            AS headcount,
       ROUND(AVG(salary),2) AS avg_salary
FROM employees
GROUP BY department
ORDER BY avg_salary DESC;

Subqueries and CTEs

Q16
What is a subquery, and what is a correlated subquery?
Answer
A subquery is a query inside another query; it runs once and hands its result up. A correlated subquery references a column from the outer query, so it runs once per outer row — which is why it can be slow.

If asked to optimise one, the usual answer is to rewrite it as a JOIN or a window function.
-- correlated: runs per row
SELECT name, salary FROM employees e
WHERE salary > (SELECT AVG(salary) FROM employees
                WHERE department = e.department);
Q17
What is a CTE and why use one?
Answer
A Common Table Expression is a named temporary result defined with WITH, available to the query that follows.

Use it for readability — a three-level nested subquery becomes three named steps you can read top to bottom. It can also be referenced more than once in the same query, which a subquery cannot. A recursive CTE additionally walks hierarchies like an org chart.
WITH dept_avg AS (
  SELECT department, AVG(salary) AS avg_sal
  FROM employees GROUP BY department
)
SELECT e.name, e.salary, d.avg_sal
FROM employees e
JOIN dept_avg d ON e.department = d.department
WHERE e.salary > d.avg_sal;
Q18
CTE or subquery or temp table — when would you pick each?
Answer
Subquery for something small and used once. CTE when it makes the query readable or you need the result twice in one statement. Temp table when the intermediate result is large, expensive to compute, and needed across several statements — and because you can index a temp table, which you cannot do to a CTE.

Window functions

Q19
What is a window function, and how does it differ from GROUP BY?
Answer
A window function computes across a set of rows without collapsing them. GROUP BY turns ten rows into one; a window function returns all ten with an extra column.

That is the whole distinction, and it is the most common window-function interview question.
SELECT name, department, salary,
       AVG(salary) OVER (PARTITION BY department) AS dept_avg,
       salary - AVG(salary) OVER (PARTITION BY department) AS gap
FROM employees;
Q20
ROW_NUMBER, RANK and DENSE_RANK — what is the difference?
Answer
On the values 100, 90, 90, 80:

ROW_NUMBER → 1, 2, 3, 4. Always distinct, ties broken arbitrarily.
RANK → 1, 2, 2, 4. Ties share a rank and the next value skips.
DENSE_RANK → 1, 2, 2, 3. Ties share, and nothing is skipped.

Pick ROW_NUMBER for deduplication, DENSE_RANK for 'the Nth distinct value'.
Q21
Find the top 3 earners in each department.
Answer
The canonical window-function question. PARTITION BY the group, ORDER BY the measure, filter on the rank in an outer query — you cannot filter a window function in WHERE, because WHERE runs before SELECT.
SELECT * FROM (
  SELECT name, department, salary,
         DENSE_RANK() OVER (PARTITION BY department
                            ORDER BY salary DESC) AS rnk
  FROM employees
) t
WHERE rnk <= 3;
Q22
What do LAG and LEAD do?
Answer
They reach into the previous or next row of the window, which is how you do month-on-month change without a self-join.
SELECT month, revenue,
       LAG(revenue) OVER (ORDER BY month) AS prev_month,
       revenue - LAG(revenue) OVER (ORDER BY month) AS change
FROM monthly;
Q23
How would you calculate a running total?
Answer
A window function with an ORDER BY inside the OVER clause. The ordering is what makes it cumulative — without it you get the grand total on every row.
SELECT join_date, salary,
       SUM(salary) OVER (ORDER BY join_date) AS running_total
FROM employees;

NULLs, keys and design

Q24
Why does = NULL not work?
Answer
Because NULL means unknown, not a value. Comparing anything to an unknown gives unknown, not true — so the row is never returned, and no error is raised. Use IS NULL and IS NOT NULL.

The same logic explains why NULL = NULL is not true, and why COUNT(column) skips them.
Q25
What is the difference between a primary key and a unique key?
Answer
Both enforce uniqueness. A primary key cannot contain NULL and there is only one per table. A unique key allows NULLs (usually one, depending on the engine) and you can have several per table.

Practical test for whether a column can be a key: distinct = count = number of rows, and no NULLs. All-values-different is not sufficient on its own.
Q26
What is a foreign key?
Answer
A column that points at the primary key of another table, which is what makes a join meaningful. It also enforces referential integrity — you cannot insert a dept_id that does not exist in departments, and depending on the rule you cannot delete a department that still has employees.
Q27
What is normalisation, and when would you denormalise?
Answer
Organising tables to remove redundancy. 1NF atomic values, no repeating groups. 2NF 1NF plus no partial dependency on part of a composite key. 3NF 2NF plus no transitive dependency — non-key columns depend only on the key.

You denormalise deliberately in reporting and warehouse tables, where read speed matters more than update anomalies and a join per query is too expensive.
Q28
What is an index, and why not index everything?
Answer
A structure that lets the database find rows without scanning the table — conceptually the index at the back of a book.

You do not index everything because each index has to be maintained on every insert, update and delete, and it takes storage. Indexes pay off on columns you filter or join on, and on high-cardinality columns; an index on a Y/N flag rarely helps.
Q29
What does COALESCE do?
Answer
Returns the first non-NULL argument. It is how you give a NULL a display value or a default in a calculation.
SELECT name,
       COALESCE(salary, 0)          AS salary_or_zero,
       COALESCE(department,'Unknown') AS dept
FROM employees;

The objects

Q01
What is the difference between a Series and a DataFrame?
Answer
A Series is one labelled column — one dimension, one dtype, plus an index. A DataFrame is a two-dimensional table: a set of Series sharing one index, each able to hold a different dtype.

Selecting a single column with df['col'] returns a Series; df[['col']] returns a one-column DataFrame.
df['salary']      # Series
df[['salary']]    # DataFrame
Q02
What is the index, and why does it matter?
Answer
The row labels. Pandas adds 0,1,2 if you do not supply one. It matters for three reasons: loc works on it, operations between objects align on it, and groupby returns results indexed by the group.

Index alignment is the one that catches people — adding two Series matches on label, not position, so mismatched indexes give NaN rather than an error.
Q03
How do you read a file into pandas?
Answer
pd.read_csv() for CSV, pd.read_excel() for a workbook, pd.read_sql() for a query. Useful arguments to mention: nrows to peek at a huge file, usecols to load only what you need, parse_dates so date columns arrive as dates rather than text, and na_values for the file's own idea of missing.

Selecting

Q04
What is the difference between loc and iloc?
Answer
loc selects by label; iloc selects by integer position.

The detail that separates answers: loc slicing includes the stop value, iloc excludes it. df.loc[0:3] returns four rows; df.iloc[0:3] returns three. On a default 0,1,2 index they look identical, which is exactly why the bug is hard to find.
df.loc[0:3]     # 4 rows - INCLUSIVE
df.iloc[0:3]    # 3 rows - exclusive
df.loc[0:2, ['name','salary']]
Q05
What are at and iat?
Answer
Single-cell accessors. at takes a row label and a column name; iat takes both as positions. They are faster than loc/iloc for one value because they skip the general machinery.

Both can be assigned to, which is the tidy way to set one cell: df.at[0,'name'] = 'David'.
Q06
How do you filter rows on more than one condition?
Answer
With & for and, | for or, and brackets around each condition.

The word and raises ValueError: The truth value of a Series is ambiguous, because and expects one True or False and you handed it a whole column. The brackets are required because & binds tighter than the comparison operators.
df[(df['dept'] == 'Tech') & (df['salary'] > 50000)]
Q07
What does the SettingWithCopyWarning mean?
Answer
Pandas is telling you it cannot be sure whether you are modifying the original DataFrame or a temporary copy, so your assignment may silently do nothing.

It is caused by chained indexing — two sets of brackets in a row. The fix is a single loc call, or an explicit .copy() if you genuinely wanted a separate object.
df[df['dept']=='Tech']['salary'] = 0     # warns, may do nothing
df.loc[df['dept']=='Tech', 'salary'] = 0  # correct

Cleaning

Q08
How do you find and handle missing values?
Answer
df.isnull().sum() gives the count per column — it works because True counts as 1. Then choose:

dropna() removes rows, and by default removes a row if any column is blank, which is more aggressive than people expect. subset= restricts it to the columns you care about.
fillna() keeps the row and substitutes a value — usually the median for a skewed numeric column, the mode or a literal 'Unknown' for a category.

There is no correct answer, only a declared one. Say which you chose and why.
df.isnull().sum()
df = df.dropna(subset=['salary'])
df['age'] = df['age'].fillna(df['age'].median())
Q09
Why did my dropna / fillna not change anything?
Answer
Because almost every pandas method returns a new object and leaves the original alone. You have to assign the result back.

df.dropna() computes and discards; df = df.dropna() keeps it. The same is true of sort_values, drop_duplicates, rename and astype.
Q10
How do you remove duplicates?
Answer
df.duplicated().sum() counts them, df.drop_duplicates() removes them. subset= limits the comparison to certain columns, and keep='first'|'last'|False controls which copy survives — keep=False drops every copy, which is occasionally what you want.
Q11
How do you change a column's type, and when does it fail?
Answer
astype(). It fails on a numeric cast when the column contains NaN — IntCastingNaNError: cannot convert non-finite values to integer — because there is no integer for 'missing'.

So the order is: handle the blanks first, convert second. pd.to_numeric(..., errors='coerce') is the forgiving alternative, turning anything unparseable into NaN.

Grouping and reshaping

Q12
Explain groupby.
Answer
Split, apply, combine. Split the rows into groups by a column, apply a function to each group, combine the results into one table.

The function must reduce each group to a single value, which is why a bare df.groupby('dept') prints nothing — it has grouped, but there is no instruction for what to show.
df.groupby('department')['salary'].mean()
df.groupby('department')['salary'].agg(['count','mean','max'])
df.groupby(['department','city'])['salary'].mean()
Q13
Why does groupby count differ from value_counts?
Answer
value_counts() and size() count rows. count inside an aggregation counts non-null values in the column being aggregated.

So a department with 49 people but one missing salary shows 49 from value_counts and 48 from the aggregation. The gap is your missing data, and groupby skips it without warning.
Q14
What is the difference between merge, join and concat?
Answer
merge combines on a shared column or index — it is the SQL join, and takes how='inner'|'left'|'right'|'outer'.
join is a convenience method that merges on the index by default.
concat glues objects together by position, adding rows (axis=0) or columns (axis=1). It matches nothing.

Shorthand: merge matches, concat stacks.
pd.merge(a, b, on='emp_id', how='left')
pd.concat([a, b])              # more rows
pd.concat([a, b], axis=1)      # more columns
Q15
Your merge returned fewer rows than you started with. What happened?
Answer
The default is an inner join, so rows with no match on the other side were dropped — silently, with no warning.

Always print len() before and after. If you need to keep everything on the left, use how='left'; the unmatched rows then arrive with NaN, which is at least visible. indicator=True adds a column showing which side each row came from, which is the fastest way to diagnose it.
Q16
What is a pivot_table, and how does it differ from groupby?
Answer
pivot_table is groupby in two directions at once — one field down the rows, another across the columns, with an aggregation in the middle. It also takes margins=True for totals and fill_value for empty cells.

It is the direct equivalent of an Excel pivot table, which makes it a good thing to mention if the role is Excel-heavy.
df.pivot_table(index='department', columns='rating',
               values='salary', aggfunc='mean')
Q17
What does apply do, and when should you avoid it?
Answer
apply runs your own function down a column or across rows. It is the escape hatch when no built-in exists.

Avoid it when a vectorised alternative exists, because apply loops in Python and is far slower on large frames. df['a'] * 2 beats df['a'].apply(lambda x: x*2) by a wide margin.

Everyday questions

Q18
How do you get a quick feel for a new dataset?
Answer
A fixed sequence, and saying it in order is itself the answer:

df.shape how big · df.head() what it looks like · df.info() types and non-null counts · df.describe() the numeric spread · df.isnull().sum() what is missing · df['col'].value_counts() for the categories.

info() tells you what is missing; describe() tells you what is strange.
Q19
What does describe() actually show, and what does it leave out?
Answer
Count, mean, standard deviation, min, the three quartiles and max — for numeric columns only. Text columns are excluded unless you pass include='all', which then adds unique, top and freq.

The useful read is comparing mean with the 50% row: a large gap means the column is skewed and the mean is being pulled by outliers.
Q20
How would you find outliers in a column?
Answer
Two standard approaches. IQR: anything below Q1 − 1.5×IQR or above Q3 + 1.5×IQR. Z-score: anything more than about 3 standard deviations from the mean.

IQR is the safer default because the mean and standard deviation are themselves distorted by the outliers you are hunting. And the judgement matters more than the method: an impossible value is a data error, an extreme but real value is a finding.
q1, q3 = df['salary'].quantile([.25,.75])
iqr = q3 - q1
df[(df['salary'] < q1-1.5*iqr) | (df['salary'] > q3+1.5*iqr)]
Q21
How do you create a new column from existing ones?
Answer
Assign to a name that does not exist. For conditional values use np.where for two outcomes, or pd.cut to band a numeric column.
df['bonus']  = df['salary'] * 0.10
df['band']   = np.where(df['salary'] > 60000, 'high', 'low')
df['bucket'] = pd.cut(df['experience'], bins=[0,2,7,100],
                      labels=['Junior','Mid','Senior'])
Q22
How do you work with dates in pandas?
Answer
pd.to_datetime() converts a text column to real dates, after which the .dt accessor gives you the parts: .dt.year, .dt.month, .dt.day_name().

Until you convert, a date column is just text and nothing date-like works. Deriving the weekday is a good example of creating a column that answers a question the raw file could not.

Data types and mutability

Q01
What is the difference between a list and a tuple?
Answer
A list is mutable and uses square brackets; a tuple is immutable and uses round ones.

Beyond the definition, the two points that show understanding: a tuple can be a dictionary key and a list cannot, because keys must be hashable; and a tuple is slightly faster and smaller, which matters when you are holding millions of them.

Use a tuple when the collection should not change — a coordinate, a database row, a fixed set of options.
t = (10, 20, 30)
t[0] = 99          # TypeError: 'tuple' object does not support item assignment
Q02
Which Python types are mutable and which are not?
Answer
Mutable: list, dict, set.
Immutable: int, float, str, bool, tuple, frozenset.

The consequence worth stating: an immutable object cannot be changed in place, so every 'change' creates a new object. That is why repeated string concatenation in a loop is slow and ''.join(...) is preferred.
Q03
What is the difference between a list and a set?
Answer
A list keeps order and allows duplicates; a set does neither. A set also gives you membership testing in roughly constant time because it is hash-based, where a list has to scan.

The everyday use is deduplication: set(my_list). The catch is that you lose the original order and cannot index into it.
entries = ['HR','Tech','HR','Sales']
print(set(entries))        # {'HR','Sales','Tech'} - order not guaranteed
print(len(set(entries)))   # 3
Q04
What is the difference between is and == ?
Answer
== compares values; is compares identity — whether they are the same object in memory.

Two lists with the same contents are == but not is. Use is only for singletons: x is None, x is True.
a = [1,2,3]; b = [1,2,3]
print(a == b)   # True
print(a is b)   # False
Q05
What is the difference between a shallow copy and a deep copy?
Answer
A shallow copy makes a new outer object but the inner objects are shared references. A deep copy recursively copies everything.

It only matters when the structure is nested — a list of lists, a dict of dicts. Changing an inner list through a shallow copy changes the original too, which is a classic source of bugs.
import copy
a = [[1,2],[3,4]]
b = a.copy()              # shallow
c = copy.deepcopy(a)      # deep
b[0][0] = 99
print(a[0][0])            # 99  - the original changed
print(c[0][0])            # 1   - untouched

Functions

Q06
What is the difference between a parameter and an argument?
Answer
The parameter is the name in the function definition. The argument is the value you pass when you call it. A small distinction, but interviewers use it to check whether terms are being used precisely.
Q07
What are *args and **kwargs?
Answer
*args collects any number of positional arguments into a tuple. **kwargs collects any number of keyword arguments into a dictionary.

They let a function accept a variable number of inputs. The order in a signature is fixed: positional, then default, then *args, then **kwargs.
def report(name, *marks, **info):
    print(name, sum(marks), info)

report('Rahul', 45, 72, 88, city='Chennai')
# Rahul 205 {'city': 'Chennai'}
Q08
What is a lambda function and when would you use one?
Answer
An anonymous single-expression function. Useful where a function is needed briefly and naming it would add nothing — as the key to sorted, or inside map and filter.

It cannot contain statements, loops or multiple expressions. If you find yourself wanting those, write a proper function.
staff = [('Rahul', 47764), ('Priya', 62990)]
print(sorted(staff, key=lambda x: x[1], reverse=True))
Q09
Explain map, filter and reduce.
Answer
map applies a function to every item and returns the same number of items.
filter keeps the items where the function is true, so you get fewer.
reduce collapses the whole sequence to one value, two at a time; it has to be imported from functools.

In modern Python a list comprehension is usually preferred to map and filter for readability.
from functools import reduce
m = [45, 72, 88, 61]
print(list(map(lambda x: x+5, m)))         # same count
print(list(filter(lambda x: x>60, m)))     # fewer
print(reduce(lambda a,b: a+b, m))          # one
Q10
What is recursion, and what must every recursive function have?
Answer
A function that calls itself. It must have a base case — a condition that stops the recursion — otherwise it runs until Python raises RecursionError.

Recursion is natural for problems that contain a smaller version of themselves: factorial, Fibonacci, walking a folder tree. It costs stack memory, so an iterative version is often preferred for deep cases.
def fact(n):
    if n <= 1:          # base case
        return 1
    return n * fact(n-1)
Q11
What is the difference between print and return?
Answer
print displays something to the screen; return hands a value back to the caller so it can be stored or used. A function with no return statement returns None.

This catches a surprising number of candidates: a function that prints cannot be used in a calculation.

Comprehensions and idioms

Q12
What is a list comprehension?
Answer
A one-line way to build a list from an iterable, optionally with a filter. It is both shorter and generally faster than an append loop because the list is sized more efficiently.

Note the two positions of if: at the end it filters; at the front, with else, it chooses a value for every item.
[n*n for n in range(1,6)]                        # [1,4,9,16,25]
[m for m in marks if m >= 60]                    # filter
['pass' if m >= 60 else 'fail' for m in marks]   # value for every item
Q13
What does enumerate do?
Answer
Gives you the index and the value together while looping, which avoids the range(len(...)) pattern. It takes an optional start value.
for i, d in enumerate(['HR','Tech','Sales'], start=1):
    print(i, d)
Q14
What does zip do?
Answer
Pairs up items from two or more iterables. It stops at the shortest one, which is a quiet source of data loss if the lengths differ.
names = ['Rahul','Priya']
sal   = [47764, 62990, 51200]
print(list(zip(names, sal)))   # 2 pairs - the third salary is dropped
Q15
What is the difference between range and a list?
Answer
range is lazy — it generates numbers on demand and stores only start, stop and step. A list of a million numbers holds a million objects in memory; range(1000000) holds three.

This is the easiest way into a question about generators and memory.
Q16
What is a generator?
Answer
A function that uses yield instead of return, producing values one at a time and remembering where it left off. It does not build the whole result in memory, which is why it matters for large files.

Reading a 10 GB log line by line is the standard example.
def squares(n):
    for i in range(n):
        yield i*i

for s in squares(5):
    print(s, end=' ')

Errors and files

Q17
How does exception handling work in Python?
Answer
try holds the risky code, except handles a failure, else runs only if nothing failed, and finally runs either way — which is where cleanup goes.

The point to make: catch a specific exception. A bare except swallows everything including bugs you wanted to know about.
try:
    v = int(value)
except ValueError:
    print('not a number')
else:
    print('worked:', v)
finally:
    print('always runs')
Q18
Name some common Python exceptions.
Answer
ValueError right type, wrong value (int('abc')). TypeError wrong type altogether ('5' + 5). KeyError dictionary key missing. IndexError list position out of range. ZeroDivisionError. FileNotFoundError. AttributeError the object has no such method, which is what you get from a typo in a method name.
Q19
Why use `with open(...)` instead of open and close?
Answer
Because with closes the file automatically when the block ends, including if an exception is raised inside it. A manual close() is skipped when the code above it fails, and the file stays locked or unflushed.
Q20
What are the file modes?
Answer
r read (default). w write — creates or wipes the file. a append. r+ read and write. Adding b makes it binary.

The one that costs people data is w: opening in write mode empties the file before you write anything.

Object orientation

Q21
What is the difference between a class and an object?
Answer
A class is the blueprint; an object is one instance built from it. One class, many objects, each with its own data.
Q22
What is __init__ and what is self?
Answer
__init__ is the constructor — it runs automatically when an object is created and sets up its starting state. self is the reference to the object being worked on, which is how each instance keeps its own attributes separate.

self is passed automatically; you write it in the definition but not in the call.
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary
Q23
Explain the four pillars of OOP.
Answer
Encapsulation — data and the methods that use it live together, with internal detail marked private.
Inheritance — a class takes the attributes and methods of a parent.
Polymorphism — the same method name behaving differently depending on the class, usually by overriding.
Abstraction — exposing what something does while hiding how.

Give a one-line example of each rather than only the definitions; that is what separates a memorised answer.
Q24
What is method overriding?
Answer
A child class defining a method the parent already has, so the child's version runs instead. super() lets the child call the parent's version first and then add to it, rather than duplicating it.
class Manager(Employee):
    def __init__(self, name, salary, team):
        super().__init__(name, salary)
        self.team = team
Q25
What is the difference between an instance variable and a class variable?
Answer
An instance variable is set on self and belongs to one object. A class variable is defined in the class body and is shared by every instance.

The classic trap is a mutable class variable — a list — which every object then shares and appends to.

Short round, usually a warm-up before pandas. Why the array exists, how it differs from a list, and broadcasting.

Arrays against listsEveryday operations

Arrays against lists

Q01
Why use a NumPy array instead of a Python list?
Answer
Three reasons, in order of how much interviewers care:

1. Vectorised operations. arr * 2 works on the whole array with no loop; a list would repeat itself instead.
2. Speed. One fixed type means the work runs as compiled C rather than interpreted Python.
3. Memory. A list holds pointers to objects; an array holds the values in one contiguous block.

The cost is that an array holds a single type.
import numpy as np
print(np.array([10,20,30]) * 2)   # [20 40 60]
print([10,20,30] * 2)             # the list REPEATS
Q02
What is broadcasting?
Answer
NumPy stretching a smaller array to match a larger one so an operation can run element by element, without copying the data.

The rule: compared from the right, each dimension must either match or be 1. A single number broadcasts to anything; a row of 3 broadcasts down a 2×3; a length-2 array against a 3-wide table raises ValueError.
m = np.array([[10,20,30],[40,50,60]])
print(m + 100)                # scalar to every element
print(m + np.array([1,2,3]))  # row reused for both rows
Q03
What is the difference between a copy and a view?
Answer
A slice of an array is a view — it shares memory, so changing the slice changes the original. .copy() gives an independent array.

This surprises people coming from lists, where a slice is a copy. It is a common source of bugs that look impossible.
a = np.array([1,2,3,4])
v = a[0:2]; v[0] = 99
print(a)          # [99 2 3 4]  - the original changed
c = a[0:2].copy() # independent

Everyday operations

Q04
What do ndim, shape, size and dtype tell you?
Answer
ndim how many dimensions. shape rows and columns as a tuple. size the total number of elements. dtype the single type they all share.

They are attributes, not methods — no brackets. Printing shape is the first move when a broadcast fails.
Q05
What does axis mean?
Answer
The direction an operation collapses. axis=0 works down the rows and gives one value per column; axis=1 works across and gives one per row.

The memorable form: axis is the direction that disappears.
m = np.array([[10,20,30],[40,50,60]])
print(m.sum(axis=0))   # [50 70 90]  per column
print(m.sum(axis=1))   # [60 150]    per row
Q06
How do you filter a NumPy array?
Answer
A condition returns a boolean array; putting it inside the brackets selects where it is True. Combine conditions with & and |, each in its own brackets — and does not work on arrays.
a = np.array([5,12,18,7,25])
print(a[a > 10])                    # [12 18 25]
print(a[(a > 10) & (a < 20)])       # [12 18]
print((a > 10).sum())               # 3  - True counts as 1
Q07
What is the difference between np.where and boolean filtering?
Answer
Filtering removes the rows that fail, so the array gets shorter. np.where(condition, if_true, if_false) keeps the length and replaces values.
np.where(a > 10, 'high', 'low')   # same length, labels
a[a > 10]                         # shorter, values only
Q08
What is the difference between reshape and flatten?
Answer
reshape rearranges the same values into different dimensions — rows × columns must equal size. flatten collapses any array into one dimension and returns a copy, so the original is unchanged.

Tests whether a candidate can interpret a number, not calculate one. Expect descriptive measures, spread, correlation, sampling and hypothesis testing — explained in plain words.

The basicsSpread and outliersRelationshipsSampling and inferenceHypothesis testing

The basics

Q01
What is the difference between descriptive and inferential statistics?
Answer
Descriptive summarises the data you actually have — you measured everybody, so you cannot be wrong, only unclear. Inferential uses a sample to make a claim about a population you did not measure, so there is always uncertainty attached.

The giveaway is the wording: 'our 200 employees average 38' is descriptive; 'employees in this industry average 38' is inferential and needs a confidence interval.
Q02
What are the four scales of measurement?
Answer
Nominal — names with no order (city, department).
Ordinal — ordered, but the gaps are not equal (Poor / Average / Good).
Interval — equal gaps, no true zero (temperature in Celsius).
Ratio — equal gaps and a true zero, so ratios make sense (salary, age, height).

The test for ratio is whether zero means 'none of it'. 20°C is not twice as hot as 10°C; ₹20,000 is twice ₹10,000.
Q03
Mean, median or mode — which would you report?
Answer
Mean when the data is roughly symmetric. Median when it is skewed or has outliers, because it is not dragged by extremes. Mode for categories, where a mean is meaningless.

The way to show judgement is to report the gap: if mean and median disagree sharply, that disagreement is itself the finding and you should say what caused it.
Q04
What is the difference between variance and standard deviation?
Answer
Variance is the average squared distance from the mean; standard deviation is its square root.

You report standard deviation because it is in the same units as the data — rupees, not rupees squared. Variance exists because squaring stops positive and negative deviations cancelling, and it behaves well mathematically.
Q05
Why divide by n−1 instead of n?
Answer
Because when you estimate the population variance from a sample, using the sample mean makes the deviations slightly too small — the sample mean sits in the middle of its own data by construction. Dividing by n−1 corrects that bias.

If you genuinely have the whole population, divide by n. Note that NumPy defaults to n and pandas defaults to n−1, which is why the two can give slightly different answers on the same column.
Q06
What is skewness?
Answer
Asymmetry. Right (positive) skew has a long tail of high values and pulls the mean above the median — income is the standard example. Left skew is the reverse.

The quick diagnostic needs no formula: compare mean and median. Mean > median means right skew.

Spread and outliers

Q07
What is an outlier and how do you find one?
Answer
A value far from the rest of the data. Two standard rules: the 1.5×IQR fences (below Q1−1.5×IQR or above Q3+1.5×IQR), or a z-score beyond about ±3.

IQR is the safer default, because the mean and standard deviation a z-score depends on are themselves distorted by the outlier.
Q08
Should you always remove outliers?
Answer
No, and this is the question that separates candidates.

Distinguish an impossible value from an extreme but real one. An age of −4 is a data-entry error — fix or remove it. A genuine very high salary is real data; removing it is editing the truth. Often the right move is to keep it, report the median alongside the mean, and say in the report that it is there.
Q09
What is the five-number summary?
Answer
Minimum, Q1, median, Q3, maximum — exactly what a box plot draws. The box spans Q1 to Q3 (the middle 50%, the IQR), the line inside is the median, the whiskers reach the furthest non-outlier points, and separate dots are outliers.
Q10
What is the empirical rule?
Answer
For a roughly normal distribution, about 68% of values lie within one standard deviation of the mean, 95% within two and 99.7% within three.

It is a fast sanity check: if your data claims 95% within one standard deviation, the distribution is not normal or something is wrong.
Q11
What is a z-score?
Answer
How many standard deviations a value sits from the mean: z = (x − mean) / sd.

Its real use is making incomparable things comparable — a mark of 78 in one exam and 65 in another can be ranked once both are expressed as z-scores.

Relationships

Q12
What is correlation, and what does the number mean?
Answer
A measure of how two numeric variables move together, from −1 to +1. +1 perfect positive, 0 none, −1 perfect negative. Roughly: below 0.3 weak, 0.3–0.7 moderate, above 0.7 strong.

Correlation only measures a linear relationship. A perfect U-shape can correlate at nearly zero.
Q13
What is the difference between Pearson and Spearman?
Answer
Pearson uses the actual values and measures a linear relationship. Spearman converts both columns to ranks first, so it measures whether they move together in order, not in proportion.

Spearman is the right choice with outliers, with skewed data, or with ordinal data. A big gap between the two is diagnostic: it usually means one extreme point is flattening Pearson.
Q14
Correlation is not causation — explain with an example.
Answer
Two variables moving together does not mean one causes the other. Three alternatives to rule out:

Coincidence — with enough variables, some will correlate by chance.
Reverse causation — B may be causing A.
A confounder — ice cream sales and drowning both rise in summer; the weather drives both.

Only a controlled experiment, or a design that handles confounders, supports a causal claim.
Q15
What is covariance, and why is correlation preferred?
Answer
Covariance measures whether two variables move together, but its magnitude depends on the units — a covariance in rupee-years is uninterpretable and changes if you switch to thousands.

Correlation is covariance divided by both standard deviations, which strips the units out and bounds it to −1..+1. That is why you can compare correlations and cannot compare covariances.

Sampling and inference

Q16
What is the difference between a population and a sample?
Answer
The population is everyone you want to describe; the sample is the subset you actually measured. A measure of a population is a parameter, a measure of a sample is a statistic.

Inferential statistics is entirely about how far you can trust a statistic as an estimate of a parameter.
Q17
Name the sampling methods.
Answer
Simple random — everyone equally likely.
Systematic — every kth record.
Stratified — split into groups and sample within each, preserving proportions.
Cluster — sample whole groups rather than individuals, usually for cost.
Convenience — whoever is easiest, and the one most likely to be biased.

Stratified is the one to mention when a subgroup is small and you need it represented.
Q18
What is sampling bias? Give an example.
Answer
When the way you selected the sample makes it unrepresentative, so no sample size fixes it.

The standard example is the 1936 Literary Digest poll: a huge sample drawn from car and telephone owners — who were wealthier than average — predicted the wrong winner, while a far smaller but representative poll got it right. Size does not cure bias. Survivorship bias and non-response bias are the other two worth naming.
Q19
What is the Central Limit Theorem and why does it matter?
Answer
Take repeated samples and the distribution of their means approaches a normal distribution as the sample size grows — even when the underlying data is not normal. Usually n ≥ 30 is treated as enough.

It matters because it is the licence for everything that follows: confidence intervals and hypothesis tests assume the sampling distribution is normal, and the CLT is why that assumption is reasonable on skewed real data.
Q20
What is a confidence interval?
Answer
A range that expresses the uncertainty in an estimate. A 95% interval means that if you repeated the sampling many times, about 95% of the intervals built this way would contain the true value.

It does not mean there is a 95% probability the true value is in this particular interval — stating that correctly is a good signal. A wider interval means less precision; it narrows as the sample grows.

Hypothesis testing

Q21
Explain hypothesis testing in plain words.
Answer
You assume nothing is going on — the null hypothesis — and ask how likely your data would be if that were true. If it would be very unlikely, you reject the null in favour of the alternative.

The steps: state the hypotheses, pick a significance level (usually 0.05), compute the test statistic and p-value, compare, conclude. You never prove the alternative; you only find the null implausible.
Q22
What is a p-value? Define it carefully.
Answer
The probability of seeing a result at least as extreme as the one you got, assuming the null hypothesis is true.

It is not the probability the null is true, and not the probability your result happened by chance. Getting that distinction right is one of the highest-signal answers in a stats round.

Small p-value → the data would be surprising under the null → reject it.
Q23
What are Type I and Type II errors?
Answer
Type I (false positive) — rejecting a null that was actually true. Its probability is α, the significance level you chose.
Type II (false negative) — failing to reject a null that was false. Its probability is β, and 1−β is the power.

They trade off: lowering α to 0.01 reduces false positives and increases false negatives. A medical screening example makes it concrete — which error costs more depends entirely on the context.
Q24
What does statistical significance actually tell you?
Answer
Only that the effect is unlikely to be noise. It says nothing about whether the effect is large enough to matter.

With a big enough sample, a trivial difference becomes significant. So always report the effect size next to the p-value, and ask whether the difference would change a decision.
Q25
Which test would you use, and when?
Answer
One-sample t-test — a sample mean against a known value.
Two-sample t-test — comparing the means of two independent groups.
Paired t-test — before and after on the same subjects.
Chi-square — a relationship between two categorical variables.
ANOVA — comparing the means of three or more groups.

The deciding questions: how many groups, and is the variable numeric or categorical?
Q26
How would you design an A/B test?
Answer
State the hypothesis and the single metric you will judge it on before starting. Randomly assign users to control and variant so the groups differ only in the change. Work out the sample size and run time in advance, then run it to completion.

The two failure modes to name: peeking — stopping as soon as it looks significant, which inflates false positives — and testing many metrics until one comes out significant, which is p-hacking. Fixing the metric and the duration up front prevents both.

A short round, usually conceptual. The rules, conditional probability, and the normal distribution everything else rests on.

The rulesDistributions

The rules

Q01
What is the difference between theoretical and empirical probability?
Answer
Theoretical comes from reasoning about the setup — a fair coin is 0.5 because there are two equally likely outcomes. Empirical comes from observation — you flipped it 1,000 times and got 0.512.

As the number of trials grows, empirical approaches theoretical. That is the law of large numbers.
Q02
What are mutually exclusive and independent events?
Answer
Mutually exclusive — they cannot both happen. A single card cannot be both a king and a queen, so P(A and B) = 0.
Independent — one happening does not change the probability of the other. Two coin flips.

They are different ideas and are often confused. In fact two mutually exclusive events with non-zero probability are necessarily dependent — knowing one happened tells you the other did not.
Q03
State the addition and multiplication rules.
Answer
Addition (or): P(A or B) = P(A) + P(B) − P(A and B). You subtract the overlap so it is not counted twice. If they are mutually exclusive the overlap is zero and it simplifies.
Multiplication (and): P(A and B) = P(A) × P(B|A). If they are independent, P(B|A) = P(B) and it simplifies to the product.
Q04
What is conditional probability?
Answer
The probability of A given that B has happened: P(A|B) = P(A and B) / P(B). You have narrowed the world down to the cases where B is true, so B becomes the new denominator.

The key insight: P(A|B) and P(B|A) are not the same, and confusing them is behind most probability mistakes.

Distributions

Q05
Describe the normal distribution.
Answer
Symmetric, bell-shaped, with mean, median and mode all at the centre. It is defined entirely by its mean and standard deviation, and the area under the curve is 1.

The empirical rule follows from it: roughly 68, 95 and 99.7 percent of values within one, two and three standard deviations. It matters because the Central Limit Theorem makes sample means normal even when the raw data is not.
Q06
What is a standard normal distribution?
Answer
A normal distribution with mean 0 and standard deviation 1. Converting to it with a z-score is what allows a single table or function to answer questions about any normal distribution.
Q07
What is the difference between a discrete and a continuous distribution?
Answer
Discrete variables take countable values — number of employees, dice rolls — and you can ask for the probability of an exact value. Continuous variables take any value in a range — height, salary — and the probability of any single exact value is zero; you can only ask about a range.

That is why probability for continuous variables is an area under the curve.
Q08
What is the difference between probability and odds?
Answer
Probability is favourable outcomes over all outcomes; odds are favourable over unfavourable. A probability of 0.25 is odds of 1 to 3. They are easy to mix up when reading a report.

Formulas and referencesLookupsCleaning and data qualityPivot tables and reporting

Formulas and references

Q01
What is the difference between a relative, absolute and mixed reference?
Answer
Relative (A1) shifts when you copy the formula. Absolute ($A$1) never moves. Mixed ($A1 or A$1) locks one part — the dollar locks whatever follows it.

The reason it matters: copying a formula that should point at one fixed cell, without the dollars, makes the reference walk down the sheet. You get wrong numbers and no error.
=K2-Q10      wrong when filled down - Q11, Q12 ...
=K2-$Q$10    correct - Q10 every time
Q02
What is the difference between COUNT, COUNTA and COUNTBLANK?
Answer
COUNT counts numbers only. COUNTA counts anything not empty, including text. COUNTBLANK counts the empty cells.

The gap between COUNTA and COUNT on the same range is your missing numeric data, which is a neat way to answer 'how would you check for blanks?' without conditional formatting.
Q03
Does AVERAGE treat a blank cell as zero?
Answer
No — it skips blanks entirely, so it divides by the count of filled cells. A cell containing 0 is counted.

This matters because =SUM(range)/COUNTA(range) and =AVERAGE(range) can disagree, and the second is almost always the one you want.
Q04
What is the difference between IF and IFS?
Answer
IF handles one test and two outcomes, and can be nested for more. IFS takes a list of condition/result pairs and returns the first that is true — much more readable than five nested IFs.

The trap with IFS is order: it stops at the first match, so a loose condition placed first swallows everything after it.
=IF(K2>50000, "High", "Low")
=IFS(H2<=2,"Junior", H2<=7,"Mid", H2>=0,"Senior")
Q05
Explain COUNTIF, SUMIF, AVERAGEIF and the ...IFS versions.
Answer
COUNTIF(range, condition) counts matches. SUMIF(range_to_test, condition, range_to_add) — note the ranges are different arguments. AVERAGEIF has the same shape.

The ...IFS versions take pairs of range and condition and require all of them to be true. Confusingly, COUNTIFS puts the criteria range first while SUMIFS puts the sum range first — worth checking every time.
=COUNTIF(D2:D201,"Tech")
=SUMIF(D2:D201,"Tech",K2:K201)
=COUNTIFS(D2:D201,"Tech",K2:K201,">50000")
Q06
How do you use a cell value inside a COUNTIF condition?
Answer
Put the operator in quotes and join it to the cell with &. Writing ">$Q$5" inside the quotes makes Excel search for the literal text, which matches nothing and returns 0 with no error.
=COUNTIF(K2:K201, ">"&$Q$5)      correct
=COUNTIF(K2:K201, ">$Q$5")       returns 0, silently

Lookups

Q07
How does VLOOKUP work, and what are its limitations?
Answer
Four arguments: what to find, the table to search, which column number to return, and exact or approximate.

Three limitations to name: it can only look right of the search column; the column index is a hard-coded number that breaks if someone inserts a column; and the fourth argument is optional, so leaving it out silently gives approximate matching.
=VLOOKUP(G2, bonus!$A$2:$B$5, 2, FALSE)
Q08
Why must the last argument of VLOOKUP be FALSE?
Answer
TRUE (or omitting it) means approximate match, which assumes the lookup column is sorted ascending and returns the largest value less than or equal to what you asked for.

On unsorted data that produces confident, wrong answers — some rows right by luck, some #N/A, with no pattern. Approximate matching has a legitimate use for banding (tax brackets, grades), but for an exact lookup it is always FALSE.
Q09
What is the difference between VLOOKUP and XLOOKUP?
Answer
XLOOKUP replaces VLOOKUP, HLOOKUP and INDEX+MATCH. It takes the lookup array and the return array as separate ranges, so it can look in any direction and does not break when a column is inserted. It defaults to exact match, and has a built-in not-found argument instead of needing IFERROR.

The catch: it needs Microsoft 365 or Excel 2021, so VLOOKUP is still what most interviews ask about.
=XLOOKUP(G2, bonus!$A$2:$A$5, bonus!$B$2:$B$5, "Not found")
Q10
What is INDEX + MATCH and why use it?
Answer
MATCH returns the position of a value in a range; INDEX returns the value at a given position. Nested, they do a lookup in any direction and survive column insertion, because MATCH finds the column by name rather than by number.
=INDEX(A2:A201, MATCH("Karthik Reddy", C2:C201, 0))
Q11
What does #N/A mean, and should you wrap everything in IFERROR?
Answer
#N/A means not available — the value you searched for is not in the table. It is usually a data problem, not a formula problem.

No. IFERROR hides the error without fixing the cause, so genuinely missing data disappears behind 'Not found' and nobody investigates. Read the errors first, understand why they are there, and hide them only once you have.
Q12
Name the common Excel errors and what each means.
Answer
#N/A lookup value not found. #REF! the reference points at a deleted cell. #VALUE! wrong data type, usually text where a number was expected. #DIV/0! dividing by zero or an empty cell. #NAME? a misspelt function name. #### is not an error at all — the column is too narrow.

Cleaning and data quality

Q13
You are given a 50,000-row sheet on a shared screen. How do you find duplicates?
Answer
State the two cases, because the interviewer is checking whether you distinguish them.

To see them: select the column, Conditional Formatting → Highlight Cells Rules → Duplicate Values.
To count them: =COUNTIF(A:A, A2) filled down, then filter for > 1.
To remove them: Data → Remove Duplicates — but take a copy of the sheet first, because it deletes permanently.

Mention that Remove Duplicates compares the columns you tick, so ticking all of them means only exact row copies go.
Q14
What is the danger of sorting in Excel?
Answer
Sorting a single column without expanding the selection moves that column's values and leaves every other column in place. The rows come apart and every record is now wrong, with no warning.

Always select the whole table, or use Data → Sort which prompts to expand. And know where Ctrl+Z is.
Q15
How do you remove unwanted spaces, and why does it matter?
Answer
TRIM removes leading and trailing spaces (and collapses internal runs to one). CLEAN removes non-printing characters that come from pasted or exported data.

It matters because a trailing space is invisible but makes two values unequal, which breaks lookups and grouping. =SUBSTITUTE(A2," ","·") is a neat way to see the problem before cleaning it.
Q16
What is Text to Columns, and what is its limitation?
Answer
Data → Text to Columns splits one column into several on a delimiter or a fixed width.

Its limitation is that it is a one-time operation. Add a row later and nothing happens — it is not watching the column. A formula, or Power Query, repeats itself; Text to Columns does not.
Q17
What are the common ways data arrives dirty, and how do you fix each?
Answer
Duplicates → Remove Duplicates. Blanks → decide to drop or fill, and say which. Inconsistent case or spelling ('HR' / 'hr' / 'H.R.') → UPPER/PROPER plus Find & Replace. Numbers stored as text → the green triangle, VALUE, or Text to Columns. Trailing spaces → TRIM. Impossible values (a negative age) → investigate, do not silently delete.

Pivot tables and reporting

Q18
Explain a pivot table and its four areas.
Answer
A tool that summarises a table by dragging fields into four areas:

Rows what goes down the side · Columns what goes across the top · Values the number to calculate · Filters which data to include.

It answers the same question as COUNTIF and SUMIF, and as SQL's GROUP BY, without writing a formula.
Q19
Why does my pivot table show Count when I wanted Sum?
Answer
Excel chooses Count when the column contains any text or blanks, and Sum when it is cleanly numeric.

Fix it with right-click → Summarize Values By → Sum. But read the heading first: 'Count of salary' and 'Sum of salary' are different questions, and the count will be lower than the row count wherever a value is blank.
Q20
Why does a pivot table not update when the data changes?
Answer
Because it is a snapshot, not a live formula. Right-click → Refresh, or Data → Refresh All for every pivot in the workbook.

Worse, adding rows below the source range is not picked up by Refresh at all, because the pivot remembers the original range — you have to change the data source, or base the pivot on a Table so it grows.
Q21
How do you show a percentage of the total in a pivot table?
Answer
Drag the same field into Values a second time, then right-click it → Show Values As → % of Grand Total.

Good practice is to show the count and the percentage. A bare '32%' hides the sample size, and 32% of 10 is a very different claim from 32% of 10,000.
Q22
What is conditional formatting used for?
Answer
Two quite different jobs, and saying both shows range. Finding bad data — highlight negatives, duplicates, blanks. Helping a reader — data bars and colour scales that make a column comparable at a glance.

With data bars, keep the numbers visible: the longest value always fills the cell, which can make a small difference look dramatic.
Q23
What makes a summary sheet good enough to send?
Answer
A title, a date, the number of rows it describes, at least one chart, and a sentence saying what the numbers mean. Put it as the first sheet so the reader does not land on raw data.

The test: could the recipient open it, understand it, and know what matters without asking you a question? That is also a good answer to 'how do you present findings'.

Which chart answers which question, what makes one misleading, and the dashboard questions that come up when the role mentions Power BI or Tableau.

Choosing a chart

Q01
Which chart would you use, and why?
Answer
Bar — compare a value across categories. The safe default.
Line — change over time, where the order of the x axis means something.
Histogram — the distribution of one numeric column.
Box plot — spread and outliers, especially across groups.
Scatter — the relationship between two numeric columns.
Heatmap — a matrix of values, typically a correlation table.

Lead with the question, not the chart: comparison, trend, distribution, relationship, composition.
Q02
What is the difference between a bar chart and a histogram?
Answer
A bar chart compares categories, the bars have gaps, and the order can be rearranged freely. A histogram shows the distribution of one numeric column split into ranges, the bars touch, and the order is fixed because the x axis is a number line.

Asked constantly, and a surprising number of candidates get it wrong.
Q03
Why are pie charts usually a poor choice?
Answer
People judge angles and areas badly, so similar slices are hard to rank — a bar chart puts them on a common baseline and is read instantly.

A pie is defensible with very few slices, when the parts genuinely make a whole, and when the point is 'one slice dominates' rather than a precise comparison. More than about five slices and it is unreadable.
Q04
When would you use a stacked bar instead of a grouped bar?
Answer
Stacked when the total matters and the parts are secondary. Grouped when you want to compare the parts against each other.

The weakness of stacked bars is that only the bottom segment sits on a common baseline, so the middle segments are hard to compare across bars.

Reading and making them honest

Q05
What makes a chart misleading?
Answer
A truncated y axis — starting at 95 instead of 0 turns a 2% change into a cliff. The commonest one.
Inconsistent scales between charts being compared.
Cherry-picked date ranges.
Dual axes scaled to manufacture a correlation.
3D effects that distort area.
No sample size, so a percentage based on 10 people looks like one based on 10,000.

A bar chart should start at zero because the bar's length is the encoding. A line chart showing a trend need not.
Q06
What makes a chart finished?
Answer
A title that states the finding rather than the variables, both axes labelled with units, a legend only when there is more than one series, readable categories, and a note of the sample size.

The test: if you have to explain it out loud, the title is not doing its job. 'Employees by department' is adequate; 'Sales is a third of the company' is better.
Q07
You plot a histogram and it is one tall bar with empty space. What happened?
Answer
An extreme outlier has stretched the axis, so almost all the data is squeezed into the first bin.

Options: investigate the outlier first, then either cap or exclude it and say so, use a log scale, or plot the sensible range and annotate the outlier separately. The useless chart is itself the finding — it told you about the outlier.
Q08
What does a box plot show?
Answer
The five-number summary: minimum, Q1, median, Q3, maximum. The box is the middle 50% (the IQR), the line inside is the median, the whiskers reach the furthest points within 1.5×IQR, and anything beyond is drawn as a separate outlier dot.

It is the fastest way to compare spread across several groups at once, which a histogram cannot do.

Dashboards and BI tools

Q09
What makes a good dashboard?
Answer
Start from who reads it and what decision it supports. Then: the most important number first and largest, a small number of charts that each answer a stated question, consistent colour with meaning attached, filters that apply to everything, and a visible as-of date.

The common failure is a wall of charts because the data was available, rather than because somebody needed it.
Q10
How do Excel skills map onto Power BI?
Answer
Pivot table → a visual. SUMIF → a measure. Rows/Columns/Values/Filters → the field wells. Power Query is literally the same editor in both products.

So the analytical thinking transfers directly; what changes is the interface and the vocabulary. That is a strong answer when the job asks for Power BI and your background is Excel.
Q11
What is the difference between a calculated column and a measure?
Answer
A calculated column is computed row by row and stored in the table, using memory. A measure is computed on the fly in the context of whatever the user has filtered or grouped by.

Use a column when you need to slice or filter by the value; use a measure for aggregations like totals and averages, which is most of the time.
Q12
What is the value of Power Query over cleaning by hand?
Answer
It records every transformation as a named, re-runnable step. Clean by hand and the work exists only in your memory; clean in Power Query and next month's file runs through the same process, in order, by somebody who is not you.

It is also non-destructive — deleting a step undoes it, because the step was an instruction rather than an edit.

The round that decides offers once the technical rounds are a tie. Process, judgement, and explaining a finding to somebody who does not want the detail.

How you work

Q01
Walk me through how you would approach a new dataset.
Answer
A sequence, said in order — the structure is what is being assessed:

1. Understand the question before opening the file. What decision does this support?
2. Understand the data — shape, columns, types, what one row represents.
3. Assess quality — missing values, duplicates, impossible values, ranges that make no sense.
4. Clean, recording what you changed and why.
5. Explore — distributions first, then relationships.
6. Analyse against the original question.
7. Communicate — the finding, the caveat, the recommendation.

Mentioning that you check what one row represents is a strong early signal.
Q02
How do you handle missing data?
Answer
First ask why it is missing, because that drives the fix. Missing at random is very different from missing because a system failed for one region all of March.

Then choose: drop the rows if there are few and they are not systematic; drop the column if most of it is empty; impute with median (safer than mean when skewed), mode for categories, or forward-fill for time series; or keep it as its own category, since 'not provided' is sometimes informative.

Whatever you choose, state it in the output. There is no correct answer, only a declared one.
Q03
How do you make sure your analysis is correct?
Answer
Concrete checks beat 'I double-check it':

Totals reconcile — the group counts add back to the row count.
Row counts before and after every join and filter.
Sanity-check against a known number somebody else already reported.
Spot-check a few records by hand.
Ask whether the answer is plausible — a 400% month-on-month jump is usually a pipeline bug.

The theme: a wrong answer in analytics usually looks exactly like a right one, so you need checks that would catch it.
Q04
Tell me about a time your analysis was wrong, or you found an error.
Answer
Use a real example and a clear structure: what you found, how you found it, what you did, what you changed afterwards.

What is being tested is whether you own it and have a system. Strong answers end with a process change — 'I now check row counts before and after every join' — rather than 'I was more careful next time'.

Trainer note: a candidate who says they have never made a mistake is either inexperienced or not checking.
Q05
You are given a question you think is the wrong question. What do you do?
Answer
Answer it, and then say why you think a different question is better — with evidence.

Refusing looks obstructive and answering silently wastes everybody's time. 'Here is the number you asked for. I also looked at X, because the thing you actually seem to be deciding is Y' is the response that gets analysts promoted.

Judgement

Q06
Sales dropped 20% last month. How would you investigate?
Answer
Do not guess a cause. Narrow it down.

1. Verify it. Is the drop real, or did the pipeline break, a region stop reporting, or the definition change?
2. Is it unusual? Compare with the same month last year — it may be seasonal.
3. Segment. Split by region, product, channel, customer type. A drop that is uniform means something broad; one concentrated in a single segment is a much smaller problem to find.
4. Decompose. Revenue is orders × value; which moved?
5. Check for external causes — a competitor, a price change, a holiday shift.

Then report what you found, what you ruled out, and what you still do not know.
Q07
A stakeholder says your number is wrong. How do you respond?
Answer
Assume they may be right. Ask what number they expected and where theirs came from — most disputes are a definition mismatch, not an arithmetic error. Different date range, different filter, different idea of what counts as 'active'.

Then walk through your logic, compare definitions, and agree one. Being defensive loses trust even when you are correct.
Q08
How do you decide which metric to use?
Answer
Start from the decision it drives. Then check that it is sensitive to what you are changing, hard to game, defined unambiguously, and available reliably.

Prefer rates to raw counts when the base changes. Be wary of averages on skewed data — a median is often the honest choice. And pair a primary metric with a guardrail, so you notice if you improve one thing by breaking another.
Q09
Your result is statistically significant but tiny. What do you report?
Answer
Both facts, in that order: the effect is real, and it is small. With a large enough sample almost anything reaches significance.

Then give the effect size in business terms — '0.2% more conversions, about 40 orders a month' — and let the reader decide whether that justifies the cost. Reporting significance alone, without magnitude, is one of the most common analyst mistakes.
Q10
How would you explain a 24% weekend-joining rate in HR data?
Answer
Treat it as a data-quality signal, not a finding. No company deliberately starts a quarter of its staff at a weekend.

So: confirm the calculation, then look upstream — are these backfilled records, a default date, a system that stamps the import date rather than the real one? Check whether they cluster around particular dates or sources.

The general principle: distinguish interesting from impossible. An unusual number is worth investigating; a number that should not logically exist is a bug until proven otherwise.

Communication

Q11
How do you explain a technical finding to a non-technical stakeholder?
Answer
Lead with the answer, not the method. They want the conclusion and what to do about it.

Then: use their vocabulary, not yours; quantify in money or customers rather than percentages alone; use one chart rather than a table; state the caveat plainly; and keep the methodology available but not in the room.

Structure that works: what we found → why it matters → what I recommend → what I am unsure about. 'The mean is skewed by an outlier' becomes 'one employee earns fifty-two lakh, which pulls the average up by about 27,000'.
Q12
What is the difference between a number and a finding?
Answer
'Average salary is ₹95,830' is a number. 'Average salary is ₹95,830, but one employee earns ₹52 lakh, so the median of ₹68,841 is the better figure to plan with' is a finding.

Both are true; only one is useful. The job is not to calculate — the tool does that — it is to say what the number means and what should be done about it.
Q13
How would you present a result you know the stakeholder will not like?
Answer
Lead with it rather than burying it, and bring the evidence and the caveats in the same breath. Separate what the data says from what you recommend, so disagreement about the recommendation does not become disagreement about the facts.

Offer what would change your mind — 'if we had three more months of data, this could look different' — which is honest and keeps the conversation open.
Q14
What would you put in a one-page summary?
Answer
A title that states the finding, the date, the number of records it covers, two or three numbers that matter, one chart, and at least one caveat.

Test it by asking: could somebody open this with no context and know what matters, without asking me a question? If they need you in the room, it is not finished.
Q15
Why do you want to be a data analyst?
Answer
Trainer note: the content matters less than whether it is specific. Generic answers about 'loving data' are forgettable.

Good answers connect something concrete the candidate did — a project, a dataset they cleaned, a question they chased — to what the role actually involves. Push for a specific example if the first answer is abstract.
Q16
Do you have any questions for us?
Answer
Trainer note: never 'no'. Coach candidates to prepare three.

Good ones: what does a typical week look like; what tools does the team actually use day to day; who consumes the analysis and how are decisions made from it; what would success look like in the first six months. These show the candidate is assessing the role, which reads as confidence.
